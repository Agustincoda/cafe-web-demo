# Ember & Oak Coffee — Coffee Shop Website Template

A reusable website template for coffee shops, bakeries and restaurants, built with Next.js and Tailwind CSS.
This is a **demo / concept project**: the brand is fictional and the photos come from [Unsplash](https://unsplash.com).

Brand name, colors, texts, photos, menu, combos and promotions are all edited from a few data files,
without touching the components.

## Tech stack

- [Next.js](https://nextjs.org) (App Router, JavaScript)
- [Tailwind CSS](https://tailwindcss.com)
- Deployed on [Vercel](https://vercel.com)

## Run it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
